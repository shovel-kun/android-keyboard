## Findings considered and rejected

- Download the ONNX model after installation: rejected for this personal build.
  The operator explicitly accepts the APK increase, so the pinned model is
  bundled and available offline with no setup or mutable runtime download.
- Send images to a hosted tagger: rejected because this app explicitly promises
  an offline, non-spying keyboard and the reference model already supports
  on-device inference.
- Copy WaifuTagger application code or its `assets/tags.json`: rejected because
  the cloned WaifuTagger commit contains no license file. Use it only as a
  behavioral reference; source labels from the Apache-2.0 model repository.
- Merge generated tags into provider `ClipboardPreviewMetadata.tags`: rejected
  because provider metadata and local inference have different provenance,
  model-version, confidence, and lifecycle requirements.
- Add confidence sliders in v1: rejected because changing a threshold below the
  persisted result floor would require a full re-tag and makes first-run UX
  substantially harder to explain. Ship versioned conservative defaults first.
